# One Very Important Question

A goofy little page for asking someone out.

- The **No** button runs away every time she tries to click it, with a new joke each time.
- The **Yes** button keeps getting bigger.
- Saying yes opens a planner to pick the **day, time and vibe**, then shows a date ticket she can send back on WhatsApp.

To have the WhatsApp button open a chat with you directly, set `EDDIE_WHATSAPP` near the top of the script in `index.html` (international format, e.g. `27821234567`).
